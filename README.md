## Инструкция по шагам

### Сценарий А: Обычная колонка (уязвимая версия / после сброса)
1. Включите «Мобильный хот-спот» в настройках Windows или раздайте Wi-Fi с ноутбука.
2. Запустите пункт **`[2] ВЗЛОМ`** (скрипт поднимет сервер eQuasar и настроит DNS).
3. Переведите колонку в режим сопряжения (сброс: выключить питание, зажать кнопку паузы, включить провод и удерживать 7 секунд до звука сброса).
4. В приложении «Дом с Алисой» подключите Станцию Лайт к вашему хот-споту.
5. Сервер передаст колонке команду активации ADB (`remoteActivation: true`), и колонка откроет порт `5555`.
6. Запустите пункт **`[4] БЕТОНИРОВАНИЕ`**.
7. Готово! Root зафиксирован, OTA и телеметрия заблокированы.

### Сценарий Б: Колонка обновилась на закрытую прошивку (Даунгрейд)
1. Включите «Мобильный хот-спот».
2. Запустите пункт **`[3] ДАУНГРЕЙД`** (сервер отдаст официальную уязвимую прошивку из папки `firmware/`).
3. Сбросьте колонку (удерживая кнопку паузы при подключении питания) и подключите её к хот-споту через приложение «Дом с Алисой».
4. Колонка запросит обновление, скачает уязвимую прошивку (3-5 минут) и перезагрузится.
5. После перезагрузки проверьте связь через пункт **`[1]`**:
   * Если порт 5555 открыт: сразу переходите к пункту **`[4] БЕТОНИРОВАНИЕ`**.
   * Если порт закрыт: запустите пункт **`[2] ВЗЛОМ`** и переподключите колонку.
6. Примените **`[4] БЕТОНИРОВАНИЕ`**.

## Комплект поставки

* **`firmware/`**: Содержит официальный подписанный архив прошивки Яндекса `0.372.1.8.4790672876.20261019.300.zip` (63 МБ), в котором сохранена уязвимость удаленной активации ADB.
* **`AGENTS.md`**: Исчерпывающее руководство для AI-ассистентов (Claude, GPT, Cursor, Antigravity) для автономного управления, диагностики и выполнения команд без участия человека.

## Что делает бетонирование

1. **3 уровня блокировки обновлений Яндекса (OTA):**
   * Подмена системного ключа `/system/vendor/quasar/ota_script.pub` на поддельный RSA-ключ. Любая официальная прошивка отклоняется на этапе проверки подписи.
   * Замена установщика `/system/vendor/quasar/device_ota_update.sh` на заглушку `exit 0`.
   * Полное исключение демона `updatesd` из конфигуратора автозапуска `/system/vendor/quasar/launch.json`.
2. **Фиксация Root и постоянный ADB:**
   * Обёртка Fortress Wrapper для `activate_adb.sh` (команды облака на деактивацию ADB блокируются).
   * Демон `rootkeeper.sh` проверяет порт 5555 каждую минуту и перезапускает службу при сбоях.
3. **Отключение телеметрии и аналитики:**
   * В `/etc/hosts` блокируются 11 серверов сбора данных и метрики (`appmetrica`, `metrica`, `clck`, `telemetry`, `yiod` и др.).
